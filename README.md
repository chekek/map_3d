# OSM → 3D

Веб-приложение: выбор участка на карте OSM → генерация 3D-модели зданий и дорог по данным OpenStreetMap → сохранение выбранного ракурса в SVG.

Работает полностью в браузере, без сборки и без сервера — только статические файлы. Использует:
- **Leaflet + Leaflet.draw** — карта и выделение прямоугольного участка;
- **Overpass API** — получение зданий (`building`, теги `height` / `building:levels`) и дорог (`highway`);
- **Three.js** (через CDN, ES-модули) — 3D-сцена, `OrbitControls` для вращения камеры, `SVGRenderer` для экспорта в SVG.

## Деплой на GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите в него три файла: `index.html`, `style.css`, `app.js` (и этот `README.md`, по желанию).
   ```bash
   git init
   git add index.html style.css app.js README.md
   git commit -m "OSM 3D viewer"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/<репозиторий>.git
   git push -u origin main
   ```
3. В репозитории откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите источник **Deploy from a branch**, ветку `main`, папку `/ (root)`.
5. Сохраните — через минуту-две сайт будет доступен по адресу вида
   `https://<ваш-логин>.github.io/<репозиторий>/`.

Никакой backend не нужен — Overpass API и тайлы OSM запрашиваются прямо из браузера пользователя.

## Ограничения

- Overpass API — общий бесплатный сервис, при больших участках (больше ~1×1 км) запрос может быть медленным или обрываться по таймауту. В интерфейсе есть подсказка выбирать участок поменьше.
- `SVGRenderer` — старый рендерер Three.js, рисующий сцену как набор плоских многоугольников (полигональная графика, без текстур и растровых теней) — то есть именно то, что нужно для чистого векторного SVG.
- Высота зданий приблизительна там, где в OSM нет тегов `height`/`building:levels` (используется 6 м по умолчанию).
