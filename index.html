  1. Найдите нужное место на карте
  2. Нажмите «Выделить участок» и нарисуйте прямоугольник
  3. Нажмите «Построить 3D»
  4. Крутите/двигайте камеру мышью — выберите ракурс
  5. Нажмите «Сохранить SVG»

Советы

Выбирайте небольшой участок (примерно до 600×600 м) — иначе Overpass API вернёт слишком много данных, и генерация будет долгой или вовсе не сработает.

Высота зданий берётся из тегов OSM height или building:levels (× 3 м). Если тегов нет — используется значение по умолчанию (6 м).

Ширина дорог оценивается по типу highway (магистраль шире, тропинка уже).
